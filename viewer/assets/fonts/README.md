# Viewer Fonts

Self-hosted Latin and Latin Extended WOFF2 subsets from Google Fonts:

- Public Sans, upright variable weights 400-700, version 21.
- EB Garamond, upright weight 700, version 33.

Both are distributed under the SIL Open Font License. The corresponding
copyright notices and licenses are included here and copied to `font-licenses/`
in the published site by `scripts/prepare.mjs`. Font binaries are bundled by
Vite; the running viewer makes no requests to Google Fonts.

Sources:

- https://fonts.google.com/specimen/Public+Sans
- https://github.com/google/fonts/tree/main/ofl/publicsans
- https://fonts.google.com/specimen/EB+Garamond
- https://github.com/google/fonts/tree/main/ofl/ebgaramond

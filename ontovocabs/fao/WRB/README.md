### Note
The RSG definitions are a bit tricky as they're done in a cascading manner, e.g. if A then type X, else if B then type Y, else...
Thus, the definitions only make sense in the context of the wider cascade.

I've found nice standalone definitions at ISRIC: https://wrb.isric.org/soilgroups/
Unclear is to which version these definitions apply to. Ideally these stand-alone definitions would be integrated to the sheets before import
